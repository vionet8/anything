# バッチ4（016〜020）横断メモ

5本すべてが模範解答にほぼ完全収束した（朝飯前、絵コンテ、具体と抽象、
後知恵バイアス、So What/Why So）。新規原則はゼロ。

## 20ケース累計

- 新規原則が生まれた（明確なズレ）: 3件（001, 002, 005） = 15%
- 有効な代替解（ズレでも収束でもない）: 1件（014） = 5%
- ほぼ完全収束: 16件 = 80%

バッチを重ねるごとに「概念の種類」「設問形式」「答えの種類
（reframe要求かチェックリストか）」という3つの仮説をそれぞれ試したが、
いずれもズレの発生を安定的に予測できなかった。20件というサンプルサイズで
見ると、ズレの発生率はおおむね15%前後で安定しつつあり、狙って再現する
方法が見つからないまま量をこなしても、新しい原則の追加ペースは
今後も同程度（5件に1件弱）で推移すると予想される。

## 判断: このペースでの量産を続けるかどうか

ここまでの結果は、当初の問い（「本を読ませればAIの思考は劇的に良くなる
のか」）に対して、かなり明確な暫定回答を与えている。量を増やしても
この結論の精度は上がるが、新しい種類の知見は出にくくなってきている
可能性が高い。ここでユーザーに状況を報告し、方針を確認する。
