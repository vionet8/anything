# 比較分析

## 結果: 収束でも失敗でもない「有効な代替解」

ブラインド解答は模範解答と同じ問題（N=1の成功例に過大な重みを置いている）
を正しく指摘した。ただし解決の道筋が異なる。

- 模範解答: この経歴の母集団全体での成功率（基準率）データを確認してから
  方針化するかどうか判断すべき、という王道の「基準率を見よ」路線。
- ブラインド解答: そもそも表面的な属性（出身大学・独学かどうか）を条件に
  するのをやめ、その候補者が実際に優秀だった**背後の行動特性**（自走力、
  問題解決への執着）を言語化し、それを測れる評価軸（コーディング課題等）
  に置き換えるべき、という「属性ではなく特性で見よ」路線。

## 評価

この2つは矛盾しない代替解であり、むしろブラインド解答の方が実務上は
筋が良い可能性がある。「地方の無名大学出身・独学」のような狭いカテゴリの
基準率データは、そもそも母数が少なく統計的に信頼できるデータが存在しない
ことが多い（採用担当者が「同様の経歴の人のデータを見てから判断を」と
言われても、データがなくて困る可能性が高い）。一方、行動特性に注目する
路線は、データがなくてもすぐに実行可能な代替案になっている。
