# バッチ3（011〜015）横断メタ分析

## 観測事実

今回は「答えがreframeを要求する概念」を意図的に選んだ（バッチ2の訂正版
仮説の検証として）。結果:

- 011（AIへのフレーミング委譲）: ほぼ完全収束
- 012（具体と抽象の往復）: ほぼ完全収束
- 013（ピラミッド構造）: ほぼ完全収束
- 014（基準率 vs 逸話）: 収束ではないが、模範解答とは異なる**有効な代替解**
- 015（振り返り作業のAI委譲）: ほぼ完全収束（模範解答を上回る具体性）

つまりバッチ2の訂正版仮説（「reframeを要求する概念なら収束しにくいはず」）
も、5件中4件が収束したことで**支持されなかった**。

## 15ケース通しての結論

3つのバッチにわたって別々の仮説（開かれた設問形式が原因→誤り、
reframeの要求度が原因→これも支持されず）を立てて検証したが、
どちらも安定した予測力を持たなかった。ここで正直に認めるべき結論は:

**「相手の計画を評価・批評してください」という形で明示的に頼まれたとき、
このモデルは既にかなり広い範囲で、前提の疑い方・優先順位の再検討・
選択肢のカテゴリの再検討を自力で行える。書籍固有の概念を知らなくても、
15ケース中10〜11ケースで模範解答にほぼ到達している。**

新しい原則が生まれた（＝明確なズレが見つかった）のは15ケース中3ケース
（001, 002, 005）のみで、狙って再現する方法はまだ見つかっていない。
概念の種類・設問形式のどちらも、ズレの有無を安定して予測する変数
ではなかった。

## この結果の意味（プロジェクトの当初の問いに戻ると）

このプロジェクトは「思考法の名著を重み付けして思考のベースにすれば、
かなり凄いパフォーマンスを出せるのでは」という問いから始まった。
15ケースの結果は、次のような留保付きの答えを示している。

- 「批評・評価を明示的に求められた状況」では、モデルは既に本の教えの
  かなりの部分を自力で再現できており、本を読んだからといって劇的に
  変わる余地は、少なくともこの種のシナリオでは大きくなさそうだった。
- ただし、見つかった3つの原則（問いの優先順位を疑う、解決策のカテゴリを
  疑う、自己申告の制約を目的から切り離す）は、いずれも「相手の話の
  内容を検証する」レベルを超えて「相手が置いた前提の外側に出る」動きで
  あり、これは実際に見つけにくく、かつ実務上価値が高い種類のズレ
  だった。量は少なくても、質的には無視できない。
- 「本を読めば凄いパフォーマンスが出る」という単純な期待よりも、
  「本の効能は、ごく一部の・狙って再現しにくい種類の盲点を塞ぐことに
  ある」という、より控えめで具体的な効能の方が実態に近そうである。

## 今後の設計指針

ズレの有無を事前に予測する変数がまだ見つかっていないため、今後は
「概念の種類」や「設問形式」を工夫するより、**量を増やして自然な
発生率（15ケース中3件、約20%）で新しい原則を拾っていく**方が
効率的かもしれない。あるいは、実際の書籍本文（grounding: quote）を
使うことで、より本の固有性が強い・チェックリスト的知識に還元されない
概念を扱えるようになり、ヒット率が上がる可能性がある。後者は
ユーザーに本文抜粋の提供を依頼する形でしか実現できない。
