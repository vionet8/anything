# 4件の比較ケースを通じて見えてきたパターン

cases/021（熟達論）, 022（コルブ）, 023（予測符号化理論）, 024（CBR）の
4件で、FPRLを他の独立した理論と直接比較した。ここで一貫して現れた
パターンを記録する。

## パターン: FPRLは「なぜ理想的な手順が省略されるか」を説明する層を持つ

比較した4つの理論は、いずれも「望ましいプロセス・構造」を記述する点では
優れている。

| 比較相手 | その理論が示す「望ましい形」 |
|---|---|
| 熟達論 | 遊→型→観→心→空、という熟達の段階 |
| コルブ | 経験→内省→概念化→実験、というサイクル |
| 予測符号化理論 | 予測誤差を検知し、モデルを更新する |
| CBR | 検索→適応→検証→更新、という事例活用の手順 |

しかし4件とも、実際のケース（停滞・変わらない・無視される・流用したい）
は「望ましい形から外れている」状態そのものが相談内容だった。ここで
FPRLは共通して、**「なぜそこから外れるのか」を説明する追加の層**
（残響・防御反応・E₂/E₃のゲート・規範的評価軸・確証バイアス）を
提供していた。

- 熟達論・コルブ・CBRは、いずれも「正しい手順のうち、どの段階が
  欠けているか」という**構造的な診断**はできるが、「なぜその段階が
  実行されないのか」という**動機づけ・心理的な診断**をする語彙を
  持たない。
- 予測符号化理論は「誤差が更新を駆動する」という機構までは説明するが、
  「大きく明瞭な誤差が、なぜ更新に変換されない、あるいは逆効果になる
  ことがあるのか」を説明する層（規範的評価軸・防御反応）を持たない。
- FPRLはこの4件すべてで、「なぜ人は望ましい手順を省略したくなるのか」
  （残響による確証バイアス、心理的コスト回避としてのe2-2、自己像を
  守るための防御反応）を一貫して提供していた。

## ブラインド解答との関係

4件とも、ブラインド解答は比較相手の理論（熟達論・コルブ・予測符号化
理論・CBR）が示す「望ましい手順」にはほぼ完全に独力で到達していた。
一方、FPRLが追加する「なぜ省略されるか」の層には、部分的にしか
到達していなかった（近い指摘はしても、残響・防御反応・ゲートのような
具体的な機構までは踏み込まない）。

## 解釈上の注意（ユーザーとの議論を受けて訂正）

当初は「4件とも比較の設計者（私）がFPRLを軸に選んでいるため、FPRLに
有利な構図になりやすい選択バイアスがかかっている」とだけ書いていたが、
これは慎重になりすぎていた。ユーザーからの指摘の通り、少なくとも
**熟達論・コルブ・CBRの3件については、比較の見せ方の問題ではなく、
内容面で実質的な差がある**。この3つの理論は、実際に「なぜ望ましい
手順から逸脱するのか」を説明する語彙を（一般的な要約のレベルでは）
持たず、FPRLがそこを具体的な機構（残響・E₂/E₃・防御反応）で埋めて、
より実行可能な診断を出せていたのは、比較の恣意性を超えた事実である。

**ただし1件だけ訂正が必要**: ケース023（予測符号化理論）で比較対象に
したのは、「予測誤差が大きいほど更新が起きる」という教科書的な単純版
だった。実際の予測符号化理論の研究には、能動的推論（active inference）
や精度重み付け（precision weighting）といった、「なぜ大きな誤差でも
無視されることがあるか」を説明する拡張が既に存在する。つまりあの
比較は、予測符号化理論の単純化されたバージョンと戦わせた可能性があり、
熟達論・コルブ・CBRの3件ほどクリーンに「FPRL固有の貢献」とは言い切れ
ない。今後この理論を再度扱う場合は、精度重み付けまで含めた比較を
すべきである。

**結論（訂正版）**: 「望ましい手順を記述する理論」と「なぜ手順から
逸脱するかを説明する理論」が性質の異なる2種類の知識である、という
構造上の観察は維持しつつ、少なくとも熟達論・コルブ・CBRの3件については、
FPRLが元の理論では扱えなかった課題を実際に解いた、という評価が妥当。
予測符号化理論との比較は、比較対象の設定に改善の余地があった。
