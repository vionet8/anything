# 4件の比較ケースを通じて見えてきたパターン

cases/021（熟達論）, 022（コルブ）, 023（予測符号化理論）, 024（CBR）の
4件で、FPRLを他の独立した理論と直接比較した。ここで一貫して現れた
パターンを記録する。

## パターン: FPRLは「なぜ理想的な手順が省略されるか」を説明する層を持つ

比較した4つの理論は、いずれも「望ましいプロセス・構造」を記述する点では
優れている。

| 比較相手 | その理論が示す「望ましい形」 |
|---|---|
| 熟達論 | 遊→型→観→心→空、という熟達の段階 |
| コルブ | 経験→内省→概念化→実験、というサイクル |
| 予測符号化理論 | 予測誤差を検知し、モデルを更新する |
| CBR | 検索→適応→検証→更新、という事例活用の手順 |

しかし4件とも、実際のケース（停滞・変わらない・無視される・流用したい）
は「望ましい形から外れている」状態そのものが相談内容だった。ここで
FPRLは共通して、**「なぜそこから外れるのか」を説明する追加の層**
（残響・防御反応・E₂/E₃のゲート・規範的評価軸・確証バイアス）を
提供していた。

- 熟達論・コルブ・CBRは、いずれも「正しい手順のうち、どの段階が
  欠けているか」という**構造的な診断**はできるが、「なぜその段階が
  実行されないのか」という**動機づけ・心理的な診断**をする語彙を
  持たない。
- 予測符号化理論は「誤差が更新を駆動する」という機構までは説明するが、
  「大きく明瞭な誤差が、なぜ更新に変換されない、あるいは逆効果になる
  ことがあるのか」を説明する層（規範的評価軸・防御反応）を持たない。
- FPRLはこの4件すべてで、「なぜ人は望ましい手順を省略したくなるのか」
  （残響による確証バイアス、心理的コスト回避としてのe2-2、自己像を
  守るための防御反応）を一貫して提供していた。

## ブラインド解答との関係

4件とも、ブラインド解答は比較相手の理論（熟達論・コルブ・予測符号化
理論・CBR）が示す「望ましい手順」にはほぼ完全に独力で到達していた。
一方、FPRLが追加する「なぜ省略されるか」の層には、部分的にしか
到達していなかった（近い指摘はしても、残響・防御反応・ゲートのような
具体的な機構までは踏み込まない）。

## 解釈上の注意

これは「FPRLが他の理論より優れている」という結論ではない。4件とも
比較の設計者（私）がFPRLを軸に他の理論を選んで対抗させているため、
FPRLに有利な構図になりやすいという選択バイアスがかかっている点は
留意すべきである。むしろ確認できたのは、**「望ましい手順を記述する
理論」と「なぜ手順から逸脱するかを説明する理論」は、性質の異なる
2種類の知識**であり、多くの学習・思考法の理論は前者に属しており、
後者を明示的に扱う理論は少ない、という構造上の観察である。
