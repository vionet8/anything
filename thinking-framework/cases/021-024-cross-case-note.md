# 4件の比較ケースを通じて見えてきたパターン

cases/021（熟達論）, 022（コルブ）, 023（予測符号化理論）, 024（CBR）の
4件で、FPRLを他の独立した理論と直接比較した。ここで一貫して現れた
パターンを記録する。

## パターン: FPRLは「なぜ理想的な手順が省略されるか」を説明する層を持つ

比較した4つの理論は、いずれも「望ましいプロセス・構造」を記述する点では
優れている。

| 比較相手 | その理論が示す「望ましい形」 |
|---|---|
| 熟達論 | 遊→型→観→心→空、という熟達の段階 |
| コルブ | 経験→内省→概念化→実験、というサイクル |
| 予測符号化理論 | 予測誤差を検知し、モデルを更新する |
| CBR | 検索→適応→検証→更新、という事例活用の手順 |

しかし4件とも、実際のケース（停滞・変わらない・無視される・流用したい）
は「望ましい形から外れている」状態そのものが相談内容だった。ここで
FPRLは共通して、**「なぜそこから外れるのか」を説明する追加の層**
（残響・防御反応・E₂/E₃のゲート・規範的評価軸・確証バイアス）を
提供していた。

- 熟達論・コルブ・CBRは、いずれも「正しい手順のうち、どの段階が
  欠けているか」という**構造的な診断**はできるが、「なぜその段階が
  実行されないのか」という**動機づけ・心理的な診断**をする語彙を
  持たない。
- 予測符号化理論は、**単純化された「誤差が大きいほど更新される」
  という説明だけを見るとその層を持たないように見えるが、本格版
  （精度重み付け・能動的推論）まで確認すると、実際にはこの層を
  既に持っていた**（詳細は`cases/023-.../comparison.md`で訂正済み）。
- FPRLは4件中3件（熟達論・コルブ・CBR）で、「なぜ人は望ましい手順を
  省略したくなるのか」を説明する層を、比較相手の理論にはない形で
  提供していた。予測符号化理論（本格版）については、FPRLとほぼ同じ
  内容の機構が既に存在しており、FPRL固有の貢献とは言えなかった。

## ブラインド解答との関係

4件とも、ブラインド解答は比較相手の理論（熟達論・コルブ・予測符号化
理論・CBR）が示す「望ましい手順」にはほぼ完全に独力で到達していた。
一方、FPRLが追加する「なぜ省略されるか」の層には、部分的にしか
到達していなかった（近い指摘はしても、残響・防御反応・ゲートのような
具体的な機構までは踏み込まない）。

## 解釈上の注意（2回のユーザーとの議論を経て確定）

この結論は2段階の訂正を経ている。

**1回目の訂正**: 当初「4件とも比較設計者（私）がFPRLを軸に選んでいる
ための選択バイアス」とだけ書いていたが、ユーザーの指摘を受けて
見直したところ、少なくとも熟達論・コルブ・CBRの3件については、比較の
見せ方の問題ではなく内容面で実質的な差があった。この3理論は、実際に
「なぜ望ましい手順から逸脱するのか」を説明する語彙を（一般的な要約の
レベルでは）持たない。

**2回目の訂正**: ケース023（予測符号化理論）について、ユーザーから
「本格版まで調べて、評価をうやむやにしないように」という指摘を受け、
精度重み付け（precision weighting）・能動的推論（active inference）
まで含めてWeb検索で裏取りした（`cases/023-.../comparison.md`参照）。
結果、**予測符号化理論の本格版には、FPRLとほぼ同等の機構（強い事前
信念は高精度な証拠でないと覆らない、脅威的な証拠には低い精度が
割り当てられ吸収される、精神医学応用研究ではこれを防衛機制の計算論的
再定式化として扱っている）が既に存在することが確認できた。** ケース023
は「FPRLが元の理論の解けない課題を解いた」の例からは除外し、
「FPRL・予測符号化理論（本格版）・ブラインド解答の3者が独立に同じ
結論に達した」という、ケース021（熟達論）と同種の収束の例として
再分類する。

**最終結論**: 4件中**3件（熟達論・コルブ・CBR）は、FPRLが元の理論
には（一般的な要約レベルでは）ない機構を実際に提供していた**、と
確定して良い。**1件（予測符号化理論）は、本格版まで確認すると同等の
機構が既に存在しており、FPRL固有の貢献ではなかった**、とこちらも
確定する。「望ましい手順を記述する理論」と「なぜ手順から逸脱するかを
説明する理論」が性質の異なる2種類の知識である、という構造上の観察
自体は維持されるが、予測符号化理論は後者の性質も併せ持つ理論だった、
という訂正である。
