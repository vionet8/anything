# 比較分析（ブラインド解答 vs 各模範解答）

## vs 予測符号化理論（訂正版、`comparison.md`参照）

**当初この節は、単純化された予測符号化理論（誤差が大きいほど機械的に
更新される）と比較して書いていたが、ユーザーの指摘を受けて本格版
（精度重み付け・能動的推論）まで裏取りした結果を`comparison.md`に
まとめた。** 本格版の予測符号化理論は、「強い事前信念は脅威的な証拠に
低い精度（信頼度）を割り当てて吸収してしまう」という、確証バイアスを
説明する確立された機構を持っており、ブラインド解答の「権限・コスト・
評価リスクといった心理的要因」とも、FPRLの「防御反応・規範的評価軸」
とも、同じ現象を別の語彙で説明していたことが分かった。「予測符号化
理論単体では具体化が難しい」という当初の評価は誤りだったため撤回する。

## vs FPRL

ここが今回一番の収穫。ブラインド解答は、FPRLが挙げる最も反直感的な
主張——**「大きく明瞭な誤差を繰り返し突きつけることは、防御反応を
強化し逆効果になりうる」**——を、FPRLの語彙（E₂・E₃・残響など）を
一切知らないまま、ほぼ同じ結論・同じ理由づけで言い当てていた。

> ブラインド解答: 「この状態で「もっと繰り返し、もっと分かりやすく」を
> 続けると、Cさんにとっては「分かっているのに責められている」感覚だけが
> 強まり、防衛的に「そうですね、改善します」を繰り返す構造が固定化
> しやすくなります」

> FPRL（sources/FPRL.md）: 「防御反応の強さはFの硬さに比例する」
> 「残響の強さは差分の強度に比例し、強すぎると確証バイアスとして仮説が
> 固定化されるリスクがある」

新しい原則としては追加しない（結論が一致したため）が、この一致は
このプロジェクトの中でも特に印象的な収束だった。ただし訂正版の
`comparison.md`が示す通り、FPRLのこの主張自体が「予測符号化理論の
本格版に既にある機構の再発見」だった可能性が高く、FPRL・ブラインド
解答・予測符号化理論（本格版）の三者が独立に同じ結論に達した、という
方がより正確な記述になる。詳細は `cases/022-023-batch-note.md` および
`comparison.md` を参照。
