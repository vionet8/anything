## 模範解答（単純版ではなく、精度重み付けまで含めた本格版）

**この改訂版は、当初書いた単純版（誤差が大きいほど機械的に更新される）
を訂正するものである。** 実際の予測符号化理論・能動的推論の研究は、
単純版よりずっと精緻で、Cさんの状況を十分に説明できる機構を既に持つ。

1. **予測誤差は、その大きさだけでなく「精度（precision）」で重み付け
   されて初めて更新に影響する。精度とは、その誤差信号がどれだけ
   信頼できるとその人（の脳）が見積もっているかを表す。** 大きく明瞭な
   誤差であっても、その人がその誤差に低い精度（＝信頼できない・
   参考にならない）を割り当てれば、更新への影響力はほとんどなくなる。
   これは検索で確認した通り、確証バイアス・動機づけられた推論の
   標準的な説明機構として、既に予測符号化理論の枠組みの中に存在する。

2. **強く保持された事前信念（例えば「自分のやり方は基本的に正しい」
   という自己像）は、それを覆すのに圧倒的に高精度な証拠を必要とする。**
   曖昧で再解釈可能な証拠は、事前信念を脅かすことなく、単に既存の
   モデルに吸収されてしまう。Cさんが「そうですね、来月は改善します」と
   受け流し続けているのは、データという証拠そのものに低い精度を
   割り当て、「今回は特殊要因だった」等の解釈で自分のモデル（自分の
   やり方は正しい）を守っている状態として説明できる。

3. **さらに、能動的推論の精神医学応用研究では、こうした精度の誤った
   配分（本来重要な脅威的情報に低い精度を割り当てること）そのものを、
   心理的な防衛機制の計算論的な再定式化として扱っている。** つまり
   「自己像を脅かす情報を無視する」という現象を、精度重み付けの異常
   として説明する枠組みは、既に確立された研究領域である。

4. **したがって「データをより繰り返し・分かりやすく伝える」方針が
   効かない理由も、この枠組みで直接説明できる。** 誤差信号の「大きさ・
   明瞭さ」をいくら上げても、Cさんの側がその情報に割り当てる「精度」
   （信頼性の見積もり）が低いままなら、更新は起きない。信号の大きさと
   精度は別の変数であり、後者に対処しない限り前者を強めても無意味、
   あるいは強すぎる誤差は逆に「例外扱い」という解釈での吸収を促し、
   むしろ既存モデルを固定化する可能性すらある。

**求められる対応の型**: 「データをより繰り返し・分かりやすく伝える」
方針にそのまま乗る前に、「Cさんはこのデータにどれくらい“信頼できる
情報”として重みを置いているか、あるいは何らかの理由で割り引いて
受け取っていないか」を確認し、信号の大きさではなく、その情報に
割り当てられている精度（信頼性の見積もり）に働きかける対応を
提案する。
