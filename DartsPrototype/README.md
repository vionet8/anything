# Darts Prototype

タップの長さ(強さ)でダーツの発射パワーを決める、コアループ検証用のプロトタイプです。
このリポジトリはヘッドレス環境で作成したため、Unity Editor上での動作確認はまだ行っていません。以下の手順でご自身のUnity Editorで開いて確認してください。

## セットアップ手順

1. Unity Hubで新規プロジェクトを作成する(テンプレート: 2D、Unity 2022 LTS以降を推奨)。
2. 作成したプロジェクトの `Assets` フォルダに、このリポジトリの `DartsPrototype/Assets/Scripts` と `DartsPrototype/Assets/Editor` フォルダをコピーする。
3. Unity Editorのメニューから `Tools > Darts > Setup Scene` を実行する。
   - カメラ、発射地点、ダーツボード、UI(スコア/ラウンド表示、パワーメーター)、ダーツのPrefabを自動生成し、`Assets/Scenes/DartsGame.unity` として保存します。
   - 見た目はすべて仮の円形スプライト(コード生成)です。見栄えは後で差し替えてください。
4. 生成された `DartsGame` シーンを開いて再生する。

## 操作方法

- 画面をタップ(またはマウスクリック)している間、パワーが溜まります(最大 `chargeDuration` 秒)。
- 離すとその時点のパワーでダーツが発射されます。
- 発射角度は `DartLauncher.launchAngle` (デフォルト55度)で固定です。
- ダーツがボードに当たると、中心からの距離でスコアが決まります(`DartBoard.rings` で設定、50/25/15/10/5点)。
- 5投(`GameManager.totalRounds`)で試技終了です。

## 実機(スマホ)で試す場合

`File > Build Settings` でAndroid/iOSに切り替えてビルドしてください。入力処理はマウスとタッチの両方に対応しています。
