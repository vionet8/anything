# 写真トーナメント

写真を1対1で見比べてタップしていくと、最後に1枚だけ残る——という決め方のアプリです。
娘の誕生日プレゼントの候補、旅行先の候補など、「言葉で比べにくいもの」を写真のまま比べられます。

## スマホで使う（おすすめ：GitHub Pages）

サーバー側の処理がない静的なアプリなので、GitHub Pages に置くだけでスマホから使えます。

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `claude/photo-tournament-feature-x4741b` の `/ (root)` にして Save
3. 1〜2分待ってから、スマホで次を開く

   `https://vionet8.github.io/anything/PhotoTournament/`

4. **ホーム画面に追加**する
   - iPhone（Safari）：共有ボタン → 「ホーム画面に追加」
   - Android（Chrome）：右上のメニュー → 「アプリをインストール」

ホーム画面から開くとアドレスバーのない全画面になり、一度開いたあとは
電波がなくても起動します（アプリ本体をキャッシュしているため）。

> **iPhone の方へ**：Safari のタブとして使うだけだと、7日間開かないうちに
> 保存した写真が iOS 側に消される場合があります。ホーム画面に追加しておけば対象外になるので、
> 大会を残しておきたいときは必ず追加してください。

### パソコンで動かす／手元で試す

```
npm install
npm start        # http://localhost:4174 を開く
```

同じ Wi-Fi のスマホからなら `http://<パソコンのIP>:4174` でも開けます
（ただし http なので、ホーム画面追加やオフライン起動は使えません）。

## 使い方

1. 「新しい大会をつくる」
2. 大会の名前（例：娘の誕生日プレゼント）を入れて、写真を選ぶ（何枚でも可）
3. 写真ごとに名前・メモ・リンクを入れる（メモとリンクは任意。値段でも、お店の名前でも、条件でも自由に書けます）
4. 「トーナメントを始める」→ 好きなほうをタップし続ける
5. 優勝写真と、ベスト4などの順位が出る

- 枚数が2のべき乗でなくても大丈夫です。足りない分は不戦勝として自動で埋めるので、
  タップする試合数はいつでも「枚数 − 1」回です。
- メモとリンクは既定では対戦中に出ません（写真だけで選べます）。準備画面のチェック、または対戦画面の
  「対戦中もメモとリンクを見る」でいつでも切り替えられます。設定は大会ごとに保存されます。
- リンクは対戦カードの外に置いてあるので、開いても勝敗にはなりません。`http` と `https` 以外は
  リンクにしないので、貼り付けたものがそのまま実行されることはありません。
- 「1つ戻す」で直前の選択をやり直せます。
- 「中断して保存」で途中終了、あとから履歴の大会をタップすれば続きから再開できます。
- 終わった大会は写真ごと履歴に残り、「同じ写真でもう一度」で組み合わせを変えて再戦できます。

## 保存について

写真と結果は、その端末のブラウザの IndexedDB に保存されます（サーバーには何も送りません）。
リポジトリが公開でも、置いてあるのはアプリだけで、写真が誰かに見えることはありません。
端末どうしの同期はないので、スマホで作った大会はスマホにだけ残ります。
取り込むときに長辺 1400px の JPEG へ縮小するので、スマホの写真をそのまま入れても容量を圧迫しにくくしています。
ブラウザのサイトデータを消すと大会も消えます。

## 中身

| ファイル | 役割 |
| --- | --- |
| `src/bracket.js` | トーナメント表の組み立て・進行・順位づけ（DOM にも保存方式にも依存しない） |
| `src/store.js` | IndexedDB への保存（使えない環境ではメモリのみ） |
| `src/app.js` | 画面の描画と操作 |
| `sw.js` | オフライン用のキャッシュ（アプリを更新したら `VERSION` を上げる。スマホ側は次に開いたときに新しくなる） |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `server.js` | 開発用の静的サーバー |

## テスト

```
npx playwright test
```

`tests/bracket.spec.js` が組み合わせのロジック、`tests/app.spec.js` が
実際のブラウザ操作（写真の取り込み → 優勝決定 → 中断・再開・再戦、連打よけ、
メモとリンクの表示切り替え、あやしいリンクの排除、ホーム画面追加用のアイコン、
オフラインでの起動）を確かめます。
